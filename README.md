# Portofolio Ihsan Rahadi

Website portofolio pribadi yang menampilkan profil, pengalaman, kemampuan teknis, proyek, dan Lab Interaktif untuk peran IT Support dan Helpdesk.

## Teknologi

- React
- Vite
- Tailwind CSS

## Menjalankan secara lokal

Pastikan Node.js dan npm sudah terpasang, lalu jalankan:

```bash
npm install
npm run dev
```

Vite akan menampilkan alamat lokal untuk membuka website.

## Pemeriksaan

```bash
npm run lint
npm run build
```

Hasil build produksi tersedia di folder `dist/`.
